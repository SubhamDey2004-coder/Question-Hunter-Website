# Subham Dey — AI/ML Engineering Portfolio

A responsive personal portfolio highlighting applied machine learning, RAG applications, local AI agents, computer-vision projects, and Python API engineering.

## Live preview

After enabling GitHub Pages, the site should be available at:

https://subhamdey2004-coder.github.io/Question-Hunter-Website/

## Built with

- HTML5
- CSS3 (responsive layout, custom design system, reduced-motion support)
- Vanilla JavaScript
- Google Fonts

## Run locally

Open `index.html` in your browser. No build tools or package installation are required.

## Deployment

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, set the source to **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for the Pages deployment to finish. GitHub will show the published URL in the Pages settings.
